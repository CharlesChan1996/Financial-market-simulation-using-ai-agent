# Financial Market Simulator

## Overview
The Financial Market Simulator is a Python-based platform for simulating financial markets with multiple interacting agents. It allows for the definition of various agent behaviors (e.g., random, technical, fundamental analysis-based) and the observation of their collective impact on a simulated market. The project aims to provide a framework for exploring agent-based modeling in finance, testing trading strategies, and understanding market dynamics under different conditions.

## Features
*   **Multi-Agent Simulation:** Supports multiple agents interacting within a simulated market.
*   **Market Environment:** Simulates daily price changes, order book dynamics, and trade execution.
*   **Configurable Agent Populations:** Allows defining the mix of different agent types, their initial capital, and other parameters.
*   **Basic Agent Learning:** Agents can learn from past "bad" buy trades and enter a cooldown period for those instruments.
*   **Extensible Agent Types:** Currently includes:
    *   `RandomAgent`: Makes random buy/sell decisions.
    *   `TechnicalAgent`: Placeholder for agents using technical indicators.
    *   `FundamentalAgent`: Placeholder for agents using fundamental analysis.
*   **Results Analysis & Plotting:** Generates summaries of agent profit/loss and plots for:
    *   Agent wealth over time.
    *   Final wealth distribution of agents.
*   **Modular Project Structure:** Organized into distinct packages for agents, market simulation, and analysis.

## Project Structure
The project is organized into the following main directories:
*   `financial_market_simulator/`: Root package directory.
    *   `agents/`: Contains the base `Agent` class and specific agent type implementations (e.g., `RandomAgent`).
    *   `market_simulation/`: Includes the `MarketEnvironment` (handles market data, order book, trade execution) and `Simulation` (manages the overall simulation loop).
    *   `results_analysis/`: Provides tools for analyzing and visualizing simulation outcomes (e.g., plotting wealth, P&L summaries).
    *   `data/`: Intended for storing input data for simulations (e.g., historical price CSVs - currently uses hardcoded example data).
    *   `results/`: Default directory for saving simulation outputs, such as plots.
        *   `plots/`: Subdirectory specifically for generated plot images.
    *   `tests/`: For unit and integration tests (not yet implemented).
*   `main.py`: A simple script to run a basic simulation example.
*   `requirements.txt`: Lists project dependencies.

## How to Run

1.  **Using the Main Example Script:**
    The primary way to run a pre-configured simulation example is through `simulation.py`:
    ```bash
    python financial_market_simulator/market_simulation/simulation.py
    ```
    This script initializes a market environment, a mix of agents, runs the simulation, and then performs basic analysis, saving plots to the `financial_market_simulator/results/plots/` directory.

2.  **Using the Simplified `main.py`:**
    A more concise example can be run using `main.py`:
    ```bash
    python financial_market_simulator/main.py
    ```
    This script runs a smaller-scale simulation and prints a profit/loss summary. Plots are not generated by default in this simpler example to keep it minimal, but can be easily added.

## Agent Types
The simulator currently supports the following agent types:

*   **`Agent` (Base Class):** Provides common functionalities like portfolio management, cash tracking, memory, and a basic learning mechanism (`evaluate_past_trades`). Its own `make_decision` method is a no-op, expecting subclasses to implement specific trading logic.
*   **`RandomAgent`:**
    *   Inherits from `Agent`.
    *   Makes random decisions to buy or sell tradable instruments.
    *   Respects the cooldown period for instruments identified as "bad buys" by the learning mechanism.
*   **`TechnicalAgent` (Placeholder):**
    *   Inherits from `Agent`.
    *   Intended for agents that would use technical analysis (e.g., moving averages, RSI) to make trading decisions.
    *   Currently, its `make_decision` method is a placeholder and does not generate trades.
*   **`FundamentalAgent` (Placeholder):**
    *   Inherits from `Agent`.
    *   Intended for agents that would use fundamental analysis (e.g., P/E ratios, company news) to assess instrument value.
    *   Currently, its `make_decision` method is a placeholder and does not generate trades.
